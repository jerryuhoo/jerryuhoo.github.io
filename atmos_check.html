A CLOSER LOOK

从一个文件，到更清晰的全貌。

01 / 03

LOOK. LISTEN. UNDERSTAND.

看见微小差异，
做出更清晰的判断。

让测量与试听彼此补充，
将交付前的检查串成一个工作流。

01 / COMPARE

母带与分轨比较

将母带与分轨求和进行波形和频谱比较，查看各声道的残差、峰值与频谱差异。

02 / DIAGNOSE

追踪差异的线索

估计可能的延迟、增益与极性变化，结合相关性和残差帮助排查问题。诊断不会修改原始音频。

03 / LISTEN

把判断交还给耳朵

共享 A/B 播放位置，单独聆听残差，跳转异常区间并循环试听。从一个测量到的差异，回到一段可以仔细听辨的声音。

04 / INSPECT

展开 ADM 元数据

检查 ADM BWF 元数据、对象与声床结构，逐项区分通过、失败、警告与未检查。

05 / MEASURE

测量 5.1 响度

明确声道映射后，测量综合响度与真实峰值。可仅查看测量结果，或使用与接收方约定的工作室参考值；自定义参考不代表平台官方规范。

06 / DOCUMENT

留下可复查的记录

将最多 20 组已加载的母带／分轨加入队列，依次检查。导出包含测量、阈值、区间与警告的独立 HTML 或 JSON 报告，也可保存 JSON 批次摘要。

BEFORE THE FINAL HANDOFF

让交付前的判断，
多一份依据。

最后一次检查，也值得与混音一样的专注。把素材、测量与听觉判断放在一起，让问题有处可查，让沟通有据可依。

Atmos Check 辅助技术审阅，不提供 Dolby Atmos 或平台交付合规认证。ADM 检查也不覆盖全部渲染与配置要求。

  1. 准备素材

    载入采样率和声道布局兼容的母带与分轨。检查 5.1 文件时，先确认素材的实际声道顺序。

  2. 阅读差异，再听一次

    选择比较方式，查看异常区间，再通过试听确认。将诊断当作线索；频谱距离并不是经过校准的可闻性指标。

  3. 记录判断，继续创作

    导出检查结果与所用设置，方便与协作者复查。与接收方确认实际交付要求，再把注意力留给创作。

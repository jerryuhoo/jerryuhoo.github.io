01 / BRIDGE

塑造低频的交接

Kick/Bass 分析 kick 尾音与未衰减的 bass，塑造关注相位的桥梁，主要面向 25–200 Hz 单音低频。拖动 HANDOFF 与 BASS 设置时间；估计不可靠时，平滑回退到交叉淡化。

02 / LEARN

一起匹配时间与电平

Learn 采集五次有效音头：前三次联合匹配 Handoff、Duration 与 Bass Gain，后两次验证。用 Pre Learn / Learned 对比，或用 Restore 恢复。Level locked 固定 Bass Gain、只学习时间；没有可靠改善时保留当前设置。

03 / LOW BRIDGE

给高频，留住原有性格

在 Kick/Bass 内启用 Low Bridge，把修正集中在低频，保留高频残差。Crossover 可预览并调整 20–2000 Hz 分频点，打开页面不会自动启用处理。分频是柔和过渡，边界附近的声音仍可能变化。

04 / SPECTRAL DUCK

让普通音轨，也能彼此让位

用 32 频带动态 EQ 缓解 Main 与 Reference 的同频竞争，例如伴奏给人声、音乐给主奏让位。通过 Amount、Depth、Attack、Release 与 Range 调整避让，连续分析音频，不要求 kick 音头或稳定音高。

05 / TRIGGER

让触发贴合你的接线

在 Kick/Bass 中，VST3 支持 Audio、Auto 与 MIDI，并使用宿主提供的 Note On 采样位置触发；AU 使用音频触发。MIDI 提供时间，kick 音频仍提供参考与 Learn 素材，乐器起音和路由延迟仍需对齐。

06 / MONITOR

分清混合预览与实际输出

Kick / Bass / Layers 与 View 集中在统一工具栏，View 只改变显示比例。Layers 是混合预览；用独立 OUT 调整最终电平（−24 至 +12 dB），检查实际 OUT L / R 峰值与 OVER，再用 Reset 清除历史读数。

07 / UNDO + A/B

放心尝试，随时回头比较

Undo / Redo 为每个实例保留最多 100 条声音操作。A/B 保存两套完整的声音参数，并支持 A→B / B→A 复制。两槽和名称随宿主工程保存；重新载入工程时，撤销历史从头开始。

08 / USER PRESETS

把值得保留的声音存下来

保存、重命名用户预设，导入 .scpreset 文件，或导出当前声音。预设只恢复声音参数，保留你的主题、窗口缩放与显示偏好；名称旁的圆点表示当前参数与所选预设不同。

09 / RMS MATCH

在更接近的电平下判断声音

Match 为不同对比状态测量代表性音频，并平滑衰减至共同的 RMS 目标。它是临时的实时试听辅助，不是 LUFS 匹配或限幅器。设置最终 OUT 前关闭 Match；它不随工程保存，离线渲染时忽略。

关闭 Match 时，Bypass ON 返回未调整电平的 Main；开启 Match 时，插件内部旁路比较可能带有 RMS 补偿。宿主旁路始终返回原始 Main，外部 kick 或参考音轨继续正常输出。Pre Learn / Learned 比较处理参数，Restore 恢复起始设置。

两类工作流都报告 0 个采样的额外音频延迟，分析与平滑仍需要响应时间。Learn 针对当前素材进行匹配，最终选择请回到完整混音中试听。

FROM ROUTING TO RHYTHM

先理清接线，
再听见变化。

侧链提供参考，不必同时加入插件输出。从默认的参考静音开始，保留原音轨通往主混音的正常接线，再按制作中的问题选择工作流。

只有在明确关闭 Drum Mute／开启 Ref on、让原始参考进入插件输出时，才需要调整或静音外部原始参考的输出，避免同一声音叠加两次。

  1. Kick/Bass：保留 kick 的独立输出

    将插件插在 bass 上，把单独的 kick 送入侧链，并让 kick 继续正常送入主混音。Drum Mute 默认开启，原始 kick 不进入插件输出，但仍参与检测、Learn 与桥梁参考。

  2. Spectral Duck：主音轨与优先参考

    Main 接需要被衰减的音轨，Sidechain 接希望优先听清的声音，并保留参考音轨的正常输出。参考在插件内默认静音，但持续参与频谱分析；Ref on 会把原始参考混入输出。

  3. 学习、对比，再回到完整混音

    在 Kick/Bass 波形页播放可用的 kick 与 bass 音频，再启动 Learn，并在合适的电平下对比 Pre Learn / Learned。Layers 无法读取外部混音总线或后续效果，还需一起检查插件 OUT 表与宿主中的完整混音。
